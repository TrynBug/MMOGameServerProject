# 스킬 시스템 정리 (서버 + 클라)

> v1 스킬 시스템 정리. 모든 코드 **컴파일 검증 완료**.
> **마법사 7개 스킬(파이어볼·얼음지대·전격방출·글라이드·순간이동·블레이즈·메테오) 클라+서버 런타임 동작 확인 완료** (2클라 원격 재현 포함).
> **타격감 juice(HitFlash/HitStop/ScalePop) + 사운드(SfxPlayer + SFX 컬럼) + telegraph 추가** — 10절 참조.
> 남은 항목은 11절 참조 (5c 게이팅 / 사망 처리 / 대미지 공식 / 메테오 파편 등).

---

## 1. 스킬시스템 개요

- 가벼운 hack & slash. 즉발 조작감 + 물량 처리가 목표. 합성 시스템 없음, 직업 2개(마법사/전사).
- **핵심 모델: 클라가 먼저 반응(예측)하고, 서버가 검증/판정한다.** (PoE식 서버 완전권위와 정반대 축)
- 스킬 1개는 **여러 페이즈의 체인**으로 표현. 각 페이즈 = 독립된 스킬 데이터 1행.
- 효과는 직교하는 축으로 표현:
  - **위치 거동(Motion) × 대미지 방식(Damage) × 모양(Shape)** — 서버 carrier 라우팅/판정.
  - **타게팅(Targeting) × 배치(Placement)** — 클라가 origin/방향을 결정하는 독립 축 (아래 7절).
- 런타임 carrier는 2종:
  - **ProjectileGroup**: 이동 투사체. 클라 hit 보고 기반. (파이어볼)
  - **AreaEffect**: 범위 대미지(장판/즉발). 서버 주도 틱. (얼음지대·전격방출·블레이즈·메테오·폭발 등)
- 서버는 투사체를 **매 tick 굴리지 않는다.** 발사 파라미터만 들고 있다가 필요한 순간(hit 보고/틱)에 위치를 즉석 계산.

### 핵심 설계 결정
- 투사체 폭발은 **별도 스킬 행**으로 분리하고 `OnHitSkillKey`로 연결 (직격≠폭발 대미지). 폭발 = 단일 틱 AreaEffect.
- 폭발의 적중 판정은 **전적으로 서버**가 한다. 클라는 "투사체가 여기서 끝났다"는 사건만 보고.
- 메테오 파편 등 "여러 개 흩뿌리기"는 예외 없이 **scatter**(링 영역 시드 랜덤 N개)로 일반화.
- **효과 중심(origin)은 클라가 Placement 규칙으로 계산해 보내고, 서버는 그 origin 을 그대로 효과 중심으로 사용**한다. (타게팅은 클라에만 있음 — 설계 원칙.)
- 이동(글라이드/순간이동)은 **결정론적**: 서버·클라가 동일한 ease-out 공식(`f=1-(1-t)^2`)으로 같은 경로를 계산해 동기화.

## 2. 서버의 책임범위와 클라의 책임범위

| 항목 | 클라이언트 | 서버 |
|---|---|---|
| 시전 입력·오토타게팅 | O (방향/타겟/중심 결정) | X (origin 그대로 신뢰) |
| 시전 즉시 반응(애니/이펙트) | O (예측) | — |
| 투사체 비주얼·이동 시뮬레이션 | O | X (위치만 필요 시 역산) |
| **투사체 직격 hit 판정(1차)** | O (먼저 검사 후 보고) | 검증만 |
| **폭발/범위 적중 판정** | X | **O (전적으로 서버)** |
| 대미지 계산·적용 | X | **O** |
| 이동(대시/블링크) 위치 | O (예측, 공유 공식) | **O (5d, 동일 공식으로 권위)** |
| 쿨타임/마나/사거리 검증 | 1차(클라가 먼저 막음) | **5c 예정** |
| 지형 충돌 판정 | O (위치 보고) | 신뢰 (핵검사 후속) |

- **직격 hit** = 클라 1차 판정 + 서버 검증. **폭발 적중** = 100% 서버 판정.
- 핵 검사는 v1에서 관대하게(또는 생략). 게임 완성도 올라간 뒤 강화.

## 3. 스킬 페이즈 시스템 + 적중 시 다른 스킬 발동

### 페이즈 체인 (시간 기반)
- 스킬 1행이 `NextSkillKey`로 다음 페이즈를 가리킨다.
- `NextTriggerTiming`(언제 다음 페이즈 발동): `OnStart` / `AfterEnd` / `AfterDelay`(+`NextTriggerDelayMs`)
- "지속시간"의 정의(체인 타이밍 기준):
  - 이동 페이즈: `MoveDurationMs`
  - 그 외: `max(FirstTickDelayMs, LifetimeMs)`
- `NextOrigin`(다음 페이즈 기준 위치): `CasterPos` / `CasterFront`(+`CasterFrontDistance`) / `PrevCenter` / `PrevEnd`
- **방향(dir)은 체인 전체가 최초 시전 dir을 공유** (v1).
- **쿨타임/마나/CastClass는 체인 진입(entry) 페이즈에서만 의미**. 후속 페이즈는 무시.
- **클라도 체인을 재생**한다 (서버는 entry 페이즈에 대해서만 CastNtf 1회 송신 → 클라가 데이터로 후속 페이즈를 타임라인 재생). 9절 참조.

### 적중 시 다른 스킬 발동 (이벤트 기반, 체인과 별개 축)
- `OnHitSkillKey`: 투사체가 hit/최대사거리/지형에 도달해 **끝났을 때** 발동할 폭발 스킬 키.
- 폭발 스킬은 일반 Area 스킬(자기 대미지/반경/틱 보유). 직격 배율(중복타격 10%)을 물려받는다.

### 스킬별 페이즈 매핑 (검산용)
- 파이어볼: 1행(Linear/ContactHit, 부채꼴 n발) + `OnHitSkillKey`=폭발행(Circle, 단일틱)
- 얼음지대: 1행(Static/Area/Obb, periodic)
- 전격방출: 1행(Static/Area/Circle, 단일틱)
- 순간이동: 1행(Mobility, Move만, 즉시 블링크)
- 글라이드: ①이동(Mobility, ease-out 대시) → ②충격파(`PrevEnd`, AfterEnd)
- 블레이즈: ①빔(Obb, Lifetime 3s) → ②화염지대(`PrevCenter`, AfterEnd)
- 메테오: ①운석(Circle, 단일틱, FirstTickDelay=낙하시간) → ②파편(scatter N개, `PrevCenter`)

> 체인 데이터 정합성 점검 완료: 모든 체인의 `NextTriggerTiming`/`NextOrigin`이 entry 행에 올바르게 입력됨(과거 두 번째 페이즈 행에 밀려있던 문제 수정). Glide=AfterEnd/PrevEnd, Blaze=AfterEnd/PrevCenter, Meteo=AfterEnd/PrevCenter. 메테오 파편 scatter 링 inner<outer(10<15) 수정.

## 4. 서버의 투사체 관리방식 (ProjectileGroup)

- **1회 시전 = 1 ProjectileGroup** (부채꼴 n발 묶음). 중복타격 감쇠가 시전 단위라 그룹으로 관리.
- 서버는 투사체를 **시뮬레이션하지 않음.** 보관: 발사 파라미터 + 방향들(dirs) + spawn 시각 + 만료시각.
- **위치는 즉석 계산**: `pos = origin + dir * speed * elapsed` (필요한 순간에만, Stage 단조 시계 `m_stageClockMs` 기준).
- **중복타격 규칙**: 1투사체 1타겟. 같은 그룹이 같은 타겟을 2번째 이상 타격 시 대미지 10% + duplication flag.
- effectId(그룹 ID)는 spawn 시 발급 → CastNtf로 클라에 전달 → 클라가 그 id로 hit 보고.
- 클라 hit 보고 처리(`OnSkillProjectileHit`): effectId로 그룹 찾고, 직격은 TryHit(소비+배율), 최대사거리/지형은 TryConsume, 그 위치에 폭발 spawn.

## 5. 서버의 범위공격 관리방식 (AreaEffect)

- "특정 시각에, 컨텐츠 스레드에서, 범위 쿼리 1회 + 대미지" 라는 단일 동작을 횟수만 달리하여 통합.
  - 단일 틱(`TickIntervalMs<=0`) = instant (전격방출, 메테오 착탄, 글라이드 충격파, 파이어볼 폭발)
  - 다중 틱(`TickIntervalMs>0`) = periodic (얼음지대, 화염지대)
- 시간은 **deltaMs 누적**. 절대 시계 불필요.
- 틱 발생 시: 위치 계산 → `Stage::QueryEnemiesInShape`(섹터 broadphase + 정밀 모양 판정) → 적마다 `ApplyEffectDamage`.
- **모양(EffectShape)**: Circle(반지름=`Radius`) / Obb(가로=`ObbWidth`·세로=`ObbLength`·forward). 판정은 전부 **X-Z 평면**. (`SkillBake` 가 ObbWidth/Length ×0.5 로 half화)
- **효과 중심**: 서버는 클라가 보낸 `origin`을 그대로 중심으로 사용. 클라가 Placement 규칙으로 계산(7절).
- **scatter**: `SpawnSkillAreaEffect`가 `ScatterCount>1`이면 `[inner,outer]` 링 영역에 seed 기반 면적균등 랜덤으로 N개. (메테오 파편)

## 6. 서버의 스킬 처리 절차

### 시전
```
클라 SkillCastReq(origin·dir·target_pos·seed) → Stage::handleSkillCastReq → SkillComponent.TryCast
  → (CastDelayMs 후) Update 에서 entry 페이즈 발동:
      bake(GameData_Skill → EffectParams)
      → ContactHit: SpawnSkillProjectileGroup(effectId 발급)
        Area:       SpawnSkillAreaEffect (+scatter)
        None+Move:  Character::ApplySkillMovement (5d)
  → entry 발동 시 BroadcastSkillCastNtf (AOI, effectId + move_distance 포함)
  → 체인이면 NextTriggerTiming 시각에 후속 페이즈 발동 (NextOrigin 으로 위치 결정)
```

### 이동 페이즈 (5d — Character::ApplySkillMovement)
```
durationMs <= 0 : 즉시 블링크 → 끝점 스냅(origin+dir*distance) + 섹터 즉시 갱신   (순간이동)
durationMs  > 0 : 감속 대시   → 매 tick advanceSkillMove, ease-out f=1-(1-t)^2     (글라이드)
                  종료 시 끝점 스냅. 강제이동 중 일반(waypoint) 이동 차단.
거리: 강제 대시=MoveDistance 고정 / 즉시 블링크=min(MoveDistance, |target_pos-origin|) 클램프.
```

### 투사체 직격/폭발 · 대미지 적용 · Stage 업데이트
- (기존과 동일) 직격/최대사거리/지형 → 위치 계산 → 직격 대미지 + `OnHitSkillKey` 폭발 spawn.
- `ApplyEffectDamage` → HP 감소 → AOI 에 `SkillDamageNtf` broadcast.
- `OnUpdate`: 시계 → 시스템/유저/캐릭터/몬스터 Update(이동 후 SkillComponent.Update=체인) → `updateSkillEffects`(AreaEffect 틱 + 만료 sweep).

## 7. 스킬데이터 컬럼 목록 (Skill 테이블, 1행 = 1페이즈)

타입: `int`=int64, `double`, `bool`, `string`, `enum`. 출력대상: `all`(서버+클라) / `client`(클라 전용) / `server`.

### 연결/메타
| 컬럼 | 타입 | 대상 | 설명 |
|---|---|---|---|
| Key | int | all | 스킬(페이즈) 키 |
| Name | string | all | 이름 |
| Job | enum EJob | all | 직업 |
| CastClass | enum ESkillCastClass | all | Stationary/Mobile/Mobility |
| IsPrimaryEligible | bool | all | 주 스킬 등록 가능 |
| OnHitSkillKey | int | all | 투사체 종료 시 발동할 폭발 스킬 키 (0=없음) |
| NextSkillKey / NextTriggerTiming / NextTriggerDelayMs / NextOrigin / CasterFrontDistance | (체인) | all | 3절 참조 |

### 타게팅/배치 (클라 전용 — origin/방향 결정)
| 컬럼 | 타입 | 대상 | 설명 |
|---|---|---|---|
| Targeting | enum ETargetingMode | **client** | None / Nearest / HighestGradeNearest |
| Placement | enum ESkillPlacement | **client** | None / Caster / Target / Forward |

- **Targeting** = 어느 적을 고르나. 클라 오토타게팅이 사용 (설계상 타게팅은 클라에만 있음).
- **Placement** = 효과 중심(origin)을 어디에:
  - `Caster`(/None) → 캐스터 위치 (투사체 발사점 / 캐스터 중심 범위)
  - `Target` → 타겟 위치 (없으면 캐스터 정면 고정거리)
  - `Forward` → 캐스터 정면 `+ dir×(ObbLength/2)` (전방 빔, 블레이즈)
- 방향(dir): 타겟 있으면 `캐스터→타겟`, 없으면 캐스터 정면.

### 타이밍/자원 (체인 진입 페이즈에서만)
| 컬럼 | 타입 | 설명 |
|---|---|---|
| CooldownMs / ManaCost / CastDelayMs / ActionLockMs / Rotation | — | (5c 게이팅에서 본격 사용) |

### 효과 종류 / 튜닝
| 컬럼 | 타입 | 설명 |
|---|---|---|
| EffectMotion / EffectDamage / EffectShape | enum | carrier 라우팅 (None/Static/Linear · None/ContactHit/Area · None/Circle/Obb) |
| DamageCoeff / Radius / ObbWidth / ObbLength | double | 대미지계수 / Circle반지름 / Obb 가로·세로 |
| ProjectileSpeed / MaxRange / ProjectileCount / FanAngleDeg | — | 투사체 |
| FirstTickDelayMs / TickIntervalMs / LifetimeMs | int | 틱 스케줄 |
| MoveDistance / MoveDurationMs | — | 이동기 (MoveDurationMs=0 → 즉시 블링크) |
| ScatterCount / ScatterInnerRadius / ScatterOuterRadius | — | 흩뿌리기 (inner<outer 링) |

### 클라 전용 컬럼 (비주얼/사운드)
| 컬럼 | 타입 | 설명 |
|---|---|---|
| ProjectilePrefabPath | string client | 투사체 prefab (Resources 경로) |
| EffectPrefabPath | string client | 범위/폭발 등 Area 이펙트 prefab (Resources 경로) |
| CastAnim | string client | 베이스 시전 트리거명 |
| TelegraphPrefabPath | string client | 위치표시 VFX prefab. 시전~임팩트 표시 후 자동 제거 (메테오 운석). 10절 |
| SfxCast / SfxShoot / SfxHit / SfxLoop | string client | 효과음 클립 경로 (시전 / 발동 / 적중 / 지속). 10절 |
| SfxHitIgnoreMs | int client | 스킬 사용 후 이 ms 동안 그 스킬 SfxHit 억제 (선행음 겹침 방지). 10절 |

### enum (GameEnum.xlsx)
- `ESkillCastClass`: None/Stationary/Mobile/Mobility

- `ENextSkillOrigin`: None/CasterPos/CasterFront/PrevCenter/PrevEnd
- `ESkillEffectMotion`: None/Static/Linear
- `ESkillEffectDamage`: None/ContactHit/Area
- `ESkillEffectShape`: None/Circle/Obb
- `ETargetingMode`: None/Nearest/HighestGradeNearest  **(신규)**
- `ESkillPlacement`: None/Caster/Target/Forward  **(신규)**

## 8. 스킬 패킷 (GamePacket, ID 8000~8999)

`PacketGenerator/Proto/GamePacket/skill_packet.proto`

| ID | 이름 | 방향 | 핵심 필드 |
|---|---|---|---|
| 8001 | SkillCastReq | C→S | skill_key, origin_x/y/z, dir_x/dir_z, seed, target_object_id, target_pos_x/z |
| 8002 | SkillProjectileHitReq | C→S | repeated SkillHitItem hits (배치) |
| 8003 | SkillCastNtf | S→C | caster_object_id, skill_key, effect_id, origin_x/y/z, dir_x/dir_z, seed, **move_distance** |
| 8004 | SkillDamageNtf | S→C | target_object_id, damage, is_duplicate, remaining_hp, is_dead |
| 8005 | SkillCastRejectNtf | S→C | (정의만, 5c 예정) |

- **`move_distance`(신규)**: 이동 스킬이 실제 사용한 거리. 원격 클라가 가변거리(순간이동) 이동을 재현하는 데 사용. 이동 아니면 0.
- origin 은 클라가 Placement 로 계산해 보냄(서버 신뢰). 투사체 hit 보고는 시전 클라만, 배치로.

## 9. 클라이언트 구현 현황 (v1) — 마법사 7개 스킬 동작 확인

> `Assets/Scripts/Game` 중심. 7개 스킬 모두 런타임 확인(2클라 원격 포함).

### 시전 진입 (SkillSystem.tryCast)
- 슬롯 `OnSkill1~4` → `tryCast(skillKey)`. (입력 슬롯 4개. 테스트용 키는 인스펙터 SerializeField.)
- 마나 선체크 → **이동/타게팅/배치로 origin·dir 결정** → 회전 → 시전 애니 → 액션락 → `SkillCastReq` 송신 → 타입별 예측.
- **이동 스킬**(EffectDamage=None & MoveDistance>0): 마우스 지면점(`MouseInputHandler.TryGetMouseGroundPoint`)을 향함.
- **그 외**: `Targeting` 모드로 대상 선택(Nearest / HighestGradeNearest) → dir → `Placement`로 origin(Caster/Target/Forward).
  - 검색 반경: MaxRange>0 이면 그 값, 아니면 `m_areaTargetRange`. 타겟 없으면 정면 `m_areaCastFallbackDistance`.

### 타입별 예측/재현
- **투사체(ContactHit)**: CastDelay 후 부채꼴 발사(서버 `computeFanDirs` 동일 공식). 콜라이더 hit/최대사거리 종료 시 그룹 보고 + **종료 위치에 OnHit 폭발(EffectPrefabPath) 비주얼**(`SpawnHitExplosionVisual`). effect_id 바인딩 후 hit 배치 플러시.
- **범위(Area)**: CastDelay 후 `spawnAreaChainPhase` — Area 비주얼 생성 + 체인(NextSkillKey) 있으면 `max(FirstTickDelay,Lifetime)` 뒤 다음 Area 페이즈 재생(재귀). 블레이즈 빔→화염지대, 메테오 운석→파편.
  - **scatter**(ScatterCount>1): `[inner,outer]` 링에 N개. 위치는 클라 로컬 랜덤(장식). 대미지는 서버가 적 위치로 판정.
  - **크기 보정**: prefab 의 `AreaVfx`(baseDiameter/baseSize) 기준으로 데이터 크기(Radius/ObbWidth/ObbLength)에 맞춰 스케일. 없으면 base=1(1유닛 전제).
- **이동(Mobility)**: `PlayerCharacter.StartSkillMove(dir, distance, durationSec)` — 서버와 **동일한 `f=1-(1-t)^2`** 로컬 예측. durationSec<=0 즉시 블링크, >0 감속 대시. 강제이동 중 일반 이동 차단. 글라이드는 종료 후 충격파(Area) 재생.

### 원격 재현 (spawnRemoteVisual, CasterObjectId != local)
- 투사체: 비주얼 전용 부채꼴(보고 안 함) + 종료 위치 폭발.
- 범위: `spawnAreaChainPhase`로 동일 재생.
- 이동: 원격 `PlayerCharacter`를 `StartSkillMove(dir, ntf.MoveDistance, duration)`로 재현(서버가 보낸 실제 거리). 글라이드 충격파도 재생.

### 타게팅 (SkillTargeting)
- `ISkillTargetingMode`: `NearestTargeting`(가장 가까움), `HighestGradeNearestTargeting`(최고 등급 중 가장 가까움, `EMonsterGrade` 값 클수록 높음).

### 시전 → 애니메이션 (PlayerCharacter)
- locomotion: `Speed`(float) 1D 블렌드(idle/walk/run), damping.
- 시전 애니: `PlayCastAnimation(trigger, castSpeed)` — ActionLock 길이에 맞춰 재생.
- CastClass 분기: Stationary(전신 + 이동잠금) / Mobile(상반신 Override 레이어) / Mobility(전신, 잠금 없음 — 강제이동이 이동 제어).

### Animator 컨트롤러 규약
- 파라미터: `Speed`(float), `Cast`(trigger), `CastSpeed`(float), `CastUpper`(trigger).
- UpperBody 레이어(이름 정확히 `UpperBody`, 상반신 마스크, Override).
- 클라 전용 데이터: `ProjectilePrefabPath`, `EffectPrefabPath`, `CastAnim`.

### 컴포넌트 위치 참고
- `SkillSystem`(허브: 시전·예측·체인 재생·폭발 비주얼·hit 플러시·DamageNtf), `Projectile`/`SkillProjectileGroup`, `SkillTargeting`,
  `PlayerCharacter`(이동+강제이동 StartSkillMove/advanceSkillMove), `MonsterObject`(Grade), `MouseInputHandler`(지면점), `AreaVfx`(이펙트 기본크기), `DamageText`.

### 클라 v1 단순화 / 임시 (나중에 교체)
- prefab 없으면 폴백 없이 경고. 풀링 미구현.
- scatter 위치 클라 로컬 랜덤(서버 mt19937 미공유) — 정확 일치는 공유 seed + RNG 포팅 후속.
- 글라이드 대시 중 지형 충돌 무시(완전 결정론). 설계의 "지형 막힘"은 후속.
- 원격 캐스터 **시전 애니 미재생**(이동/이펙트만) — 후속.
- 투사체 크기 데이터 미연동(prefab 스케일 + 콜라이더 0.3 폴백).
- 시전 클립 기본 길이 = `m_castClipBaseLength` 하나 공유.

## 10. 타격감 juice + 사운드 (클라 전용)

> 전부 클라 연출 레이어 — 서버 무관. 설계 근거·튜닝은 `타격감_설계.md`.

### 피격 juice — `onSkillDamageNtf` 오케스트레이션
피격 대상이 몬스터면 적중 1프레임에 동시 발화 (가해자=플레이어는 안 건드림 — 즉발 조작감):
- **HitFlash** (`HitFlash.cs`): 몬스터 머티리얼을 **인스턴스화**해 `_BaseColor`를 빨강으로 강도 보간 후 감쇠 복원. MPB는 커스텀 SRP 셰이더에서 CBUFFER가 깨져 화면이 어두워지므로 인스턴스를 직접 수정(몬스터당 1회 인스턴스화·재사용). 연타 시 강도 리셋(비깜빡).
- **HitStop** (`HitStop.cs`): **애니메이션만 정지**(`animator.speed=0`) N ms. 위치는 안 멈춤 — 원격 보간 시각이 정지 중에도 흘러 해제 시 순간이동하기 때문. duplicate 타격은 더 짧게.
- **ScalePop** (`ScalePop.cs`): 아트 트랜스폼 80ms `1.0→1.12→1.0` 팝.
- 셋 다 캡 없음(대상당 비용 0). 컴포넌트는 첫 피격 시 `AddComponent`로 자동 부착(prefab 무관).

### 사운드 — `SfxPlayer` + 데이터 컬럼
- **`SfxPlayer`** (`SfxPlayer.cs`, 싱글톤 자동생성): 클립 1개를 `Resources.Load`·캐시 후 **±8% 피치 변주**로 재생. AudioSource 풀(16) 라운드로빈 = voice cap. 2D(v1).
  - **뭉친 타격 합치기(coalesce)**: 같은 클립이 70ms 내 또 울리면 새 보이스 대신 **기존 보이스 볼륨만 가산**(상한 1.0) → 동시 적중의 위상 간섭("피치 올라간 듯한" 거친 소리) 제거 + 많이 맞을수록 묵직.
  - **`PlayLoop(path, pos, dur)`**: 전용 소스로 루프 재생 후 dur 에 정지(지속음).
- **SFX 슬롯** (값 = Resources 클립 정확 경로):
  - `SfxCast` — 시전 시작(`tryCast`).
  - `SfxShoot` — **발동(entry, CastDelay 경과) 순간**. **모든 타입**(투사체·장판·이동기), 로컬/원격, entry 1회(체인 페이즈 제외).
  - `SfxHit` — 적중음. **투사체는 클라 hit 판정 시 0지연**(`SpawnHitExplosionVisual`, source 스킬 행 `SfxHit`). 장판·즉발은 `onSkillDamageNtf`(서버 권위). `onSkillDamageNtf`는 클라 예측(투사체 ContactHit + OnHit 폭발)의 적중음을 **중복 재생 안 함**.
  - `SfxLoop` — entry 페이즈 지속(`areaPhaseDurationSec` = 운석 낙하 FirstTickDelay / 장판 Lifetime) 동안 루프 후 정지.
- **`SfxHitIgnoreMs`(int)** — 스킬 사용 후 이 ms 동안 그 스킬 `SfxHit` 억제(선행음+첫 틱 적중음 겹침 방지). 사용 시각은 `tryCast`에서 `m_skillUseTime[skillKey]` 기록, 두 적중음 지점에서 `(now−사용시각)<값` 검사.

### 위치표시 telegraph
- `TelegraphPrefabPath` → `spawnTelegraph`: 착탄 origin 에 표시, `Radius`로 스케일(AreaVfx 규약), lifetime 후 자동 제거. 로컬=`tryCast`(CastDelay+FirstTickDelay), 원격=`spawnRemoteVisual`(FirstTickDelay). → 임팩트 시 사라짐. (메테오 운석)

### 컴포넌트/파일 (신규)
- `HitFlash` · `HitStop` · `ScalePop` · `SfxPlayer`. 배선·telegraph는 `SkillSystem`.
