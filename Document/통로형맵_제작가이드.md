# 통로형 맵 제작 가이드 (SyntyForest 스타일)

ToS 샤울레이 서쪽 숲 문법의 맵을 추가 제작하기 위한 절차서.
레퍼런스 구현: `Client/Assets/Scenes/NavMeshBuild/SyntyForest.unity` (2026-07-04 완성, 유일한 현행 필드맵 스타일).
※ SyntyField4(개활지형)·SyntyPond(연못형)는 폐기됨 — 참고만 하고 신규 제작은 이 문서 방식으로.

## 구조 문법
- **walkable = 방(원, r 9~20) ∪ 통로(Catmull-Rom 스플라인 + 폭 8~12m)** 의 SDF. 나머지는 +4m 식생 둔덕으로 차단
- 경계에 2옥타브 지터(파장 7m/±1.2 + 2.6m/±0.4)로 아메바 윤곽
- 막다른 골목 2~3개(랜드마크 보상), 개울이 둔덕을 협곡으로 뚫고 여울(floor 24.05)로 통로를 가로지름
- 높이 규약: 지면 25 / 수면 24.2 / 개울바닥 23.6 / 연못 23.4 / 둔덕 +4 (heightScale 40, 터레인 원점중심 오프셋 -mapSize/2)

## 생성 절차 (Unity execute_code 절차생성, 스테이지별 저장·확인)
1. **씬+터레인**: TerrainData(240맵 기준 513/512/디테일320, `SetDetailScatterMode(InstanceCountMode)` 필수 — Unity6 기본 Coverage는 함정), 레이어17·디테일10은 Terrain_SyntyField200에서 승계. Demo 무드(안개 Linear 20~600 크림색, 웜 태양 1.6 + 쿨 필라이트 0.5, Demo 볼륨 프로파일 공유, WindZone). 계층: root { BlockVolume, NavRoot(NavMeshSource areaId1) { Terrain, Props }, Visual }
2. **하이트맵**: 방/통로 SDF+지터 → 25+micro(±0.15), 둔덕 smoothstep 2.5m에 걸쳐 +4(미관상 완만 유지 — 급경사로 만들 필요 없음, 차단은 서버가 함), 상단 롤링노이즈+원경 상승, 개울 협곡·폭포 스텝(상류 27.0)·연못 그릇, 여울 가드. **지형 재조각 시 배치물 sink 기록→재스냅 필수**
3. **스플랫 (15레이어)**: 통로=Sand 기본+SandDark(다져진 흙)+SandDesert+회색 Pebbles(방 중앙)+PebSand 2종 타일링 교차 + **길 위 잔디·꽃 패치**(nPatch 8.5m 임계 0.51, 가장자리 짙게) / 경사=**중턱 암벽 Rockwall**(dW 0.7~2.2 밴드)+Leaves 3종 / 상단=Grass+Grass2 모틀 / **길↔절벽 이음새 밴드**(dW -2.5~+1.5, 절벽 하단에서 감쇠) / 물가 젖은 Mud. DistField cell 규약: 하이트맵 mapSize/(res-1), 알파·디테일 mapSize/res
4. **디테일 풀**: 클럼프 구조(Demo 통계: 커버 ~10%, 코어 빽빽/프린지 성김/빈터), 암벽 밴드엔 풀 제외, 갈대는 물가 높이밴드, 스플랫과 동일 시드 공유
5. **수면**: River_Plane 타일링(개울 8m/연못 격자), 폭포 프리팹(피벗 상단, 아래로 10m — y스케일로 낙차 맞춤), 커버리지 홀 스캔
6. **벽 식생**: dW 1.5~24 그리드 4.2m 채움 + 백드롭. **남향 저수종 규칙**: 북쪽 8m 지점이 통로 높이면 그 벽은 카메라를 가림 → 덤불·소형만
7. **절벽 데코**: 대형 바위(크기 비례 이격: dW ≥ 0.5+반경×0.55, 최대치수 5.5m 이하, 쿼터뷰 가림 판정 — 북쪽 통로와의 거리 d, 상단이 길높이+0.9d 초과 금지), GrassEdge 오버행(립, 콜라이더 비활성), 밑단 고사리, 립 수목(북쪽 벽만)
8. **가장자리·랜드마크**: 잔돌 라인+풀 포기(통로 테두리), 막다른 골목 성소/보물, 교차로 유적, 게이트 기둥, 가을 구역 등 지역 표정
9. **차단 볼륨**: 수역 밴드(top = 여울바닥-0.07) + **고도 밴드(하한 = walkable 최고지면 스캔 +0.45 자동산출** — 하드코딩 금지)
10. **NavMesh**: NavMeshBuilder.Build(settings, 스테이지명) — 클라 StreamingAssets + 서버 OUTPUT 자동. 검증 프로브: 방 전체 통행 / 사면·상단·수역 NO POLY / 여울 통행 / 게이트→전체 방 경로
11. **프리팹**: root를 Resources/Prefabs/Stages/<이름>.prefab 으로 SaveAsPrefabAsset (씬이 소스, 수정 시 재저장)
12. **게임데이터**: Common/GameData/Stage.xlsx·StageStartPosition.xlsx(원본) + 클라/서버 CSV 4개 동시 갱신. 스폰 Y는 NavMesh FindNearestPoly로 실측

## 표준 규칙 (시행착오에서 확정)
- **오브젝트 스케일**: Synty 실측 스케일은 쿼터뷰에서 왜소 — 나무·관목 ×2.0, 길가풀 ×1.8, 잔돌 ×1.7, 랜드마크·GrassEdge ×1.6, 디테일 프로토타입 ×1.6 을 **처음부터** 적용
- **NavMesh 입력 최소화**: 잔돌·절벽바위·랜드마크는 Visual(비입력). 낮은 장식은 밟고 지나감. 유의미 장애물(돌담·기둥·그루터기)만 **박스 NavMeshBlockVolume**(프리팹 치수표×스케일+0.4, yaw 동기)
- **투명 물리벽 불필요**: 서버 위치권위 구조라 콜라이더는 이동에 관여 안 함 (클릭 레이캐스트 간섭만 함)
- 검증은 항상 자동 프로브로 — 수동 확인 금지 (바위가 방 하나 막았던 사고를 프로브가 잡았음)

상세 수치·시드·좌표는 메모리 `synty-forest-corridor-map.md` 참조.
