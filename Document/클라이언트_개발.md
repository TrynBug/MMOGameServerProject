


## 폴더 의존 방향

UI ──┐
     ├──→ Game ──→ Packet ──→ Network ──→ (Generated, Plugins)
Game ┘

Network: 소켓·스레드·바이트 송수신만. Unity 의존성 최소화 (가능하면 순수 C#).
Packet: Packet ID ↔ 핸들러 매핑(PacketDispatcher), 직렬화/역직렬화 헬퍼. Network 위에 얹힘.
Game: 게임 로직. 패킷 핸들러를 등록해서 자기 상태를 갱신.
UI: Game을 호출해서 입력을 전달. 패킷을 직접 만들지 않음.
